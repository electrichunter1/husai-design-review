# HUSAI design review

[Open the gallery](https://electrichunter1.github.io/husai-design-review/) · [Add a design](https://electrichunter1.github.io/husai-design-review/contribute.html)

Browse designs, save favorites, compare up to four, and share a shortlist link. Public labels and downloads use neutral design IDs.

To contribute, export a self-contained SVG or still PNG under 5 MB and use **Add a design**. Submissions appear after maintainer review and merge. A GitHub account is needed to submit; browsing requires no account.

For repository contributions and the one-command import workflow, see [CONTRIBUTING.md](CONTRIBUTING.md).

The site is static. GitHub Actions validates and builds each pull request, then deploys merged changes to GitHub Pages. There are no browser API keys or upload credentials in the site.

Favorites stay in your browser. A shared shortlist link contains only neutral design IDs and display choices. It is not a shared vote tally.
