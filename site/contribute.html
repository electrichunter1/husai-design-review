Submit your artwork

  1. Export the design.Use a self-contained SVG or a still PNG, under 5 MB. Include only the artwork.
  2. Attach it on GitHub.Open the short submission form, attach your file, and add any useful notes. A GitHub account is required.
  3. Review, then publish.A maintainer checks the file and merges it. The gallery updates automatically with a neutral design ID.
